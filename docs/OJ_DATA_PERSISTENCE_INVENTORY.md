## Local business archive

Commercial Desk now offers explicit, organization-scoped **Export local business data** and **Restore missing from archive** actions. Export reads only the current OJ page's origin `localStorage`, copies supported organization-keyed commercial, fleet, estimate, field, equipment and crew-handoff records into an unencrypted JSON archive, records byte counts and per-record SHA-256 hashes plus an archive-manifest SHA-256, and never deletes or changes the source keys. Preview and unrelated keys are excluded. Restore validates the 20 MiB maximum, organization, supported keys, duplicate keys, sizes, per-record hashes and archive hash before showing confirmation. It writes only absent keys; existing local values are left unchanged. If browser storage rejects a write, it rolls back only keys written by that attempt. Hashes detect corruption, but are not signatures or proof of origin.

This is a browser recovery export, not the encrypted PC backup/analytics node. Repeat it independently for each authorized OJ origin, browser profile and founder device and store each file in a private protected location. Local database, customer data and downloaded archives are intentionally not checked into Git.

The currently attached browser sessions did not contain an authenticated OJ Workspace origin. Therefore no actual Oscar/Jacob localStorage record was inspected, exported or restored in this run; originals remain untouched. Use the export action from each authorized signed-in OJ origin, profile and device, retain the downloaded files privately, then use **Restore missing from archive** only in the intended organization. Imports are local browser recovery only and do not populate shared Supabase records.
